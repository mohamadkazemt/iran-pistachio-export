# راهنمای فنی و مدیریت پرتال شرکت بازرگانی اسلامی
### هلدینگ تجارت بین‌المللی و زنجیره تأمین صادرات محصولات کشاورزی ارگانیک و ممتاز دیمه

این سند راهنمای رسمی توسعه، راه‌اندازی، نگهداری امنیتی و عملیاتی پرتال جامع هماهنگی و بازرگانی هلدینگ **«بازرگانی اسلامی»** (با برند بین‌المللی **Eslami Global Trading**) بر روی سرورهای لینوکس (توزیع اوبونتو) است.

---

## 🚀 ماژول‌ها و ساختار کلی پلتفرم

پلتفرم بازرگانی اسلامی به صورت فول‌استک (Full-Stack) با معماری ترکیبی **Vite SPA (Client React)** به همراه **سرور هماهنگ‌کننده Express (Node.JS CJS Node System)** طراحی شده است. اهداف اساسی پروژه شامل موارد زیر است:

1. **سازگاری کامل با راست‌چین (RTL/LTR)**: نمایشگر هماهنگ با فونت‌های زیبا و مفاخر فارسی، تراز شدن خودکار پهپادها و المان‌ها با تغییر زبان فعال در هدر.
2. **پیش‌فاکتور خودکار بر اساس اینکوترمز (Incoterms 2020)**: مشتریان بین‌المللی می‌توانند درخواست‌های خرید فله و کانتینری خود را تحت قوانین حمل و نقل بین‌المللی مانند (FOB, CIF, CFR, EXW) ثبت نمایند.
3. **دستیار هوشمند تجارت گمرکی (Gemini AI)**: پاسخگویی زنده به سوالات مربوط به گواهینامه‌های فیتوسانیتری، بهداشت گیاهی قرنطینه، کدهای تعرفه گمرک (HS Code) و موارد دیگر به صورت کاملاً سروری برای حفظ کامل کدهای محرمانه API.
4. **کنسول مدیریت جامع (Admin Panel)**: بخش اپراتورها جهت پایش ورودی‌های جدید به سیستم، تأیید درخواست‌ها، جابجایی وضعیت فایل‌ها، بررسی امتیاز هرزنامه فرستنده و تهیه نسخه‌های پشتیبان داینامیک.

## ⚡ کانال راه‌اندازی خودکار (فرآیند نصب یک کلیکی)

برای پیاده‌سازی همه‌جانبه‌ی این محصول روی سرور اختصاصی اوبونتو خود، کافی است اسکریپت از پیش ساخته شده‌ی هوشمند را با دسترسی بالاترین مدیر سیستم (`root`) فراخوانی کنید:

```bash
sudo bash install.sh
```

### این اسکریپت جادویی چه کارهایی انجام می‌دهد؟
* بسته‌های به روز سیستم شما را پایش کرده و مخازن بروز Node.js v22 را سوار می‌کند.
* ابزارها و وب‌سرور **Nginx**، ابزار خودکارسازی SSL رایگان **Certbot**، به هم پیوست کنترل فرآیندهای پس‌زمینه **PM2** و همچنین نرم‌افزار ایمن‌سازی ضد نفوذ **Fail2ban** را پیکربندی و فعال‌سازی می‌کند.
* پروژه‌ی شما را به صورت کاملاً بهینه کمپایل کرده و خروجی فشرده‌ی `dist/` را تشکیل می‌دهد.
* یک کلاستر فعال در پس زمینه اوبونتو با نام `eslami-global-trading-app` ایجاد راه‌اندازی و در برابر ریستارت خودکار لایو سرور تضمین می‌کند.

## 🛠️ راه‌اندازی دستی در محیط توسعه و لوکال

اگر علاقه‌مندید تغییراتی در هسته به صورت محلی ایجاد کنید، از سناریوی زیر استفاده نمایید:

```bash
# ۱. دریافت بسته‌های پیش‌نیاز
npm install

# ۲. اجرای سرور توسعه دو طرفه (همزمان کدهای سرور و کلاینت)
npm run dev
```
سایت به صورت زنده بر روی درگاه `http://localhost:3000` دردسترس است. پس از اتمام کار، برای خروجی نهایی دستور زیر را صادر کنید:
```bash
npm run build
```

## 🔑 ورود به میز مدیریت مرکزی (کنترل پنل اپراتور)

از طریق آیکون ورود در پنل هدر وب‌سایت یا با مراجعه مستقیم به پیوند زیر وارد سامانه اداری شوید:

* **آدرس ورودی سیستم:** `https://yourdomain.com/admin`
* **مشخصات ورود پیش‌فرض:**
  * **نام کاربری (Username):** `admin`
  * **کد عبور امنیتی (Password):** `Admin123456!`

> 🛡️ **نکته امنیتی بسیار مهم**: در اولین مرتبه ورود موفق، سریعاً به پایین‌ترین بخش کنترل‌پنل ارجاع پیدا کنید و در کادر **تغییر رمز عبور مدیریت**، کد رمز جدید و پیچیده‌ای را متصل کنید تا کلیدهای قدیمی در دیتابیس بومی به صورت رمزگذاری‌شده غیرفعال شوند.

## 🤖 فعال‌سازی موتور هوش مصنوعی (مدیریت کلیدهای Gemini)

پرتال برای هدایت هوشمند مشتریان بین‌المللی خود نیاز به دریافت توکن معتبر از پلتفرم **Google Gemini** دارد. 

کافی‌ست این پارامتر را در فایل `.env` واقع در ریشه پروژه مقداردهی نمایید:
```env
PORT=3000
NODE_ENV=production
GEMINI_API_KEY=AIzaSy...YourActualGeminiApiKey...
```
سرور Express کلاینت را به صورت پراکسی هدایت می‌کند، بنابراین کلیدهای شما هرگز توسط مرورگر بارگذاری و کشف نمی‌شوند.

## 🗄️ استراتژی‌های پیشگیری و مدیریت فایل‌های پشتیبان

سیستم از ساختار پایگاه‌داده ساختاریافتگی JSON در قالب لایه‌های شی‌گرا استفاده می‌کند. داده‌های سیستمی و هویتی در فایل های زیر فشرده می‌شوند:
* مسیر فایل پایگاه‌داده: `src/db.json`
* فایل پشتیبان‌گیری داینامیک: با کمک دستور زیر می‌توانید یک کپی امن فشرده حاوی فایل‌های استاتیک، لاگ‌ها، پی‌دی‌اف‌های بازرگانی و تنظیمات دایرکتوری در فرمِ `tar.gz` ایجاد کنید:

```bash
bash backup.sh
```
فایل پشتیبان نهایی در پوشه `./backups/` صادر و ذخیره می‌گردد. همچنین با استفاده از پنل مدیریت می‌توانید ثبت بکاپ‌های جابجا شده را مستقیماً فراخوانی کنید.

## 🚑 عیب‌یابی و عارضه‌یابی خطاهای متداول

### ۱. خطا در برقراری اتصال با سرور گمرکی (Gemini)
* **دلیل معمول:** مسدود بودن آی‌پی‌های سرور توسط گوگل یا عدم معرفی متغیر `GEMINI_API_KEY` در فایل ریشه `.env`.
* **راه‌حل:** اجرای عیب‌یابی لاگ‌های سیستم با دستور `bash logs.sh` و اطمینان از صحت اعتبارسنجی کلید API.

### ۲. بروز مشکل در اجرای به روزرسانی‌های گیت
* **راه‌حل:** جهت تسهیل به‌روزرسانی قالب مفاخر بدون حذف کارهای انجام شده، دستور اتوماتیک زیر را که کدهای گیت را دریافت، مجدداً کامپایل و فرآیند خوشه‌سازی PM2 را اعمال مجدد (بدون قطعی وبسایت) می‌کند، اجرا نمایید:
```bash
bash update.sh
```
